Questão 1: Complete o código da classe ContaBancaria com os atributos numero e saldo.

}
Questão 2: Complete o código do construtor da classe ContaBancaria que inicializa os atributos numero e
saldo.
public ContaBancaria(int numero, double saldo) {
    this.numero = numero;
    this.saldo = saldo;
}
Questão 3: Complete o código do método depositar que adiciona um valor ao saldo da conta.
public void depositar(double valor) {
    if (valor > 0) {
        this.saldo += valor;
    }
}
Questão 4: Complete o código do método sacar que subtrai um valor do saldo da conta, se o saldo for
suficiente.
public void sacar(double valor) {
    if (valor > 0 && saldo >= valor) {
        this.saldo -= valor;
    } else {
        System.out.println("Saldo insuficiente!");
    }
}
